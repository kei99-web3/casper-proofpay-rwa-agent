# Code of Conduct

## Our Pledge

We want this project to be a focused, respectful environment for reviewing and improving an agentic Casper Testnet proof-of-concept.

Participants are expected to:

- be respectful and constructive
- keep feedback technical and evidence-based
- avoid harassment, personal attacks, or discriminatory language
- avoid sharing private keys, seed phrases, wallet files, credentials, or customer data

## Enforcement

Project maintainers may remove comments, issues, pull requests, or other contributions that are unsafe, abusive, off-topic, or that disclose sensitive information.

## Scope

This code of conduct applies to project spaces including issues, pull requests, discussions, and related review channels.
